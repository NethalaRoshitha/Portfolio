# 🌐 Task 1 - Responsive Portfolio Website

## 📌 Objective

The objective of this project is to design and develop a responsive personal portfolio website using HTML, CSS, and Bootstrap.  
The website showcases personal skills, projects, and contact details with a modern user interface and mobile-friendly design.

---

## 🚀 Features

- Fully Responsive Design
- Modern Navigation Bar
- Hero Section with Introduction
- About Section
- Skills Section
- Projects Showcase
- Contact Section
- Resume Download Button
- GitHub & LinkedIn Links

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Git & GitHub
